This folder contains information related to the CM1 runs in the Flournoy et al. (MWR) storm-environment modification study.

The simulations were conducted using CM1r21.0 with modifications to cm1.F and solve1.F to include the tendency nudging convection initiation technique (Flournoy and Rasmussen 2023). The modified files are available here. Other run-specific files (input_sounding and namelist.input) are provided for each simulation.
